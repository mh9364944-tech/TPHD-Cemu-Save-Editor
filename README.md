## 🌱 Why This Exists

Years ago, a small community of Twilight Princess HD players noticed that tweaking their adventure usually meant juggling half a dozen scattered tools — a hex editor here, a texture pack manager there, a save file ripper somewhere else. The experience felt like assembling a puzzle with missing corners.

TPHD Save Alchemy Lab was born from a simple desire: **one window, many powers**. Instead of chasing utilities across forum threads, players can open a single companion application that understands Cemu's environment, respects original game data, and gives creators a canvas to work on.

## 🔮 Core Philosophy

We believe a companion tool should feel like an extension of the game, not a separate chore. Three principles guide every feature:

1. **Transparency over trickery** — every change is visible, reversible, and documented.
2. **Respect for the source** — original assets are never damaged; modifications live alongside them.
3. **Craft over shortcuts** — tools are built to help players *understand* their adventure, not skip it.

Think of this project as a librarian for your save files and a colorist for your visuals — patient, precise, and always on your side.

## 🧪 Save Alchemy Engine

The heart of the toolkit. This module reads Cemu's save structure for Twilight Princess HD and presents it as an interactive, browsable map. You can:

- **Browse Chapters & Flags** — see progress markers, dungeon states, and item slots in plain language.
- **Duplicate Profiles** — clone a playthrough to branch into parallel experiments.
- **Compare Snapshots** — diff two saves side-by-side, highlighting the exact bytes that changed.
- **Restore Points** — automatic rolling backups stored in a dedicated vault folder.
- **Export Summaries** — generate human-readable journey reports for sharing or archiving.

All operations are **non-destructive by default**. The engine writes to a shadow copy first, validates it, and only then promotes it — like a careful calligrapher who drafts on scratch paper before the final ink.

## 🎨 Graphics Profile Tuner

Cemu's graphical backend offers many levers, and pulling the right ones can feel like tuning an orchestra blindfolded. This tuner bundles curated presets for:

- Resolution scaling (native, 2×, 4×, custom)
- Shadow quality tiers
- Ambient occlusion intensity
- Texture filtering modes
- Frame pacing options
- Aspect ratio adjustments for ultrawide displays

Each preset ships with a plain-language explanation, so you always know *why* a setting matters — not just *what* it changes. Presets are stored as portable profile files you can trade with friends.

## 🏗️ Architecture at a Glance

The toolkit is organized into loosely coupled modules:

- **Core Layer** — file I/O, hashing, configuration persistence
- **Alchemy Module** — save parsing and transformation
- **Tuner Module** — graphics preset management
- **Studio Module** — packaging pipeline
- **UI Layer** — responsive shell with theme engine
- **Bridge Layer** — optional scripting sandbox for plugins

Modules communicate through a documented internal event bus, which means contributors can work on one area without breaking another. Clean seams make for calm code.

## ❓ Frequently Asked Questions

**Is this affiliated with the original game's publishers?**
No. This is an independent, fan-made companion tool with no official ties.

**Will using the Lab affect my saves?**
Only if you ask it to. Every modification is preceded by an automatic backup, and the Integrity Guardian blocks writes that fail validation.

**Do I need programming experience?**
None at all. The interface is designed for players first and tinkerers second.

**Can I contribute a translation?**
Yes — translation files live in a dedicated folder and are reviewed by native speakers before merge.

**Does it work without an internet connection?**
Almost entirely. Only the live support channel and preset exchange require connectivity.
